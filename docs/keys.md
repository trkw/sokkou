# キー操作

## 何も打っていないとき

| キー | 動き |
| --- | --- |
| `C-j` | ひらがな |
| `C-k` | アプリに渡す（カタカナのモードには入らない） |
| `C-q` | 半角カナ（もう一度でひらがな） |
| `C-l` | 英数（全角英数からも） |
| `C-L` | 全角英数 |
| `/` | abbrev を始める（下） |
| 英数キー / かなキー | 英数 / ひらがな |
| Ctrl-Space（macOS の「前の入力ソースを選択」） | 英数 ⇔ ひらがな |
| ほかの Ctrl キー | アプリに渡す |

英数は「sokkou (英数)」、それ以外は「sokkou (日本語)」の入力ソースで、英数とそれ以外の行き来は入力ソースの切り替えになる。macOS の札とメニューバーのアイコンに出る。カタカナ・半角カナ・全角英数への切り替えは日本語の入力ソースの中なので、sokkou の札で見せる。

モードはアプリごとに覚え（更新や再起動のあとも残る）、別のアプリに移るとそのアプリで最後に使ったモードに戻す（ターミナルは英数から）。同じアプリの中では、選んだ入力ソースに従う。

## 打っている途中（自動変換）

| キー | 動き |
| --- | --- |
| Enter / `C-m` / `C-j` | 確定 |
| Space | 空白を打つ |
| Shift+Space / ↓ / `C-n` | 文節選択に入る |
| ← → / `C-b` `C-f` | 文節選択に入って区切りを縮める・伸ばす |
| Backspace / `C-h` | 1 打鍵消す |
| Esc / `C-g` | 1 回目は打ったままのかなに戻す、2 回目で取り消す |
| `C-k` `C-q` `C-L` | 全体をカタカナ・半角カナ・全角英字にする |
| `C-l` | 打った英字のまま確定して英数モードに入る |
| Shift+Enter | 最初の文節だけ確定 |
| `;` | ここまでを確定して ▽ を始める（`;;` は `;` を打つ） |
| Tab | 読みをユーザー辞書の読みで補完して ▽ にする（補完できなければ確定して Tab をアプリに渡す） |

## 文節選択

| キー | 動き |
| --- | --- |
| Space / `C-n` / ↓ | 次の候補。2 回目で候補の窓を開く |
| `C-p` / ↑ | 前の候補 |
| a s d f j k l | 窓の候補を選んで次の文節へ（最後の文節なら確定） |
| `X` | 窓で選んでいる候補を消す（ユーザー辞書から消し、以後は出さない） |
| `C-f` `C-b` / → ← | 区切りを伸ばす・縮める |
| Shift+← → | 選ぶ文節を移す。両端では反対の端へ回り、打った直後の Shift+← は最後の文節を選ぶ |
| Enter / `C-m` / `C-j` | すべて確定 |
| Shift+Enter | 選んでいる文節まで確定 |
| `C-g` / Esc / Backspace | 窓を閉じる、もう一度で打っている途中に戻る |
| ほかの文字 | すべて確定してから打つ |

## ▽ ▼（自分で区切る）

| キー | 動き |
| --- | --- |
| `;` + 読み | ▽ を始める（数字からも始められる。`;3kai` → 3回 ３回 三回） |
| Tab | 読みをユーザー辞書の読みで補完する。もう一度で次の読み |
| `;` か大文字 | 送り仮名を始める。送り仮名まで読めたらすぐ ▼ |
| Space / `C-n` | ▼ にする・次の候補（2 回目で窓） |
| `C-p` | 前の候補 |
| `X` | ▼ の候補を消す |
| Enter / `C-m` / `C-j` | 確定 |
| `C-g` | ▼ から ▽ に戻る、もう一度で取り消す |
| `C-k` `C-q` | 読みをカタカナ・半角カナで確定 |
| `C-l` `C-L` | 打った英字・全角英字で確定 |

## abbrev（`/`）

何も打っていないときに `/` を打つと、続く英数字を読みにして辞書を引く（`/github` → GitHub）。

| キー | 動き |
| --- | --- |
| Space | 辞書に語があれば ▼。無ければ `/` を付けたまま確定して空白を打つ（`/remind me` はそのまま打てる） |
| `C-n` / ↓ | 辞書に語が無くても ▼ にする（打った英字・全角英字・登録） |
| Enter / `C-m` | `/` を付けたまま確定 |
| `//` | `/` を 1 つ打つ |
| 英数字以外 | `/` を確定してから打つ |

## 単語の登録

候補の最後にある「登録…」を選ぶと（Space / `C-n` で送るか、窓のキーで選ぶ）、`［登録 よみ］` が出て登録する語を打てる。
登録する語は普段どおり自動変換で打ち、`C-k` でカタカナ、`C-l` で英数にもできる。

| キー | 動き |
| --- | --- |
| Enter / `C-m` | 打った語を登録して確定 |
| `C-g` / Esc | 登録をやめて元の候補に戻る |
| Backspace / `C-h` | 打った語を 1 文字消す |

登録した語は、文節選択では変換エンジンの候補のすぐ次（`C-n` 1 回）に、▽ では最初に出る。送り仮名のある読み（`;kaKu`）では語幹だけを登録する（SKK と同じ「かk /書/」）。

## 数字

読みの数字は SKK の数値変換と同じく `#` の見出しでも辞書を引く（SKK-JISYO.L の `#がつ /#1月/#3月/` など）。
候補に半角の数字があれば、`3,000` `３０００` `三千` `三〇〇〇` の書き方も候補に足す。

## SKK の手触り

設定の窓の「SKK」で 1 つずつ切り替えられる。既定はすべて使う。

| 機能 | キー | 動き |
| --- | --- | --- |
| 確定を取り消す | `C-/` | 確定した直後に押すと、確定した文字列を未確定に戻す。自動変換は文節選択に、▼ は同じ候補の ▼ に戻るので、そのまま選び直せる。次のキーを打つか、カーソルの前が確定した文字列でなければ（読めないアプリを含む）、`C-/` はアプリに渡す |
| ▽ の q でカタカナ | `q` | ▽ の読みをカタカナにして確定（SKK と同じ） |
| x で前の候補 | `x` / Space | ▼ の `x` で前の候補、最初の候補なら ▽ に戻る。候補の窓では Space で次のページ、`x` で前のページ（最初のページなら窓を閉じる）。文節選択でも窓の中だけ同じ |
| 句読点で確定 | `,` `.` `!` `?` | 打っている途中に打った句読点が 、。！？ になったら、そこまでを確定する。英語に続く句読点は打ったままで確定しない |
| 読みの続きを薄く見せる | Tab | ▽ で、ユーザー辞書の読みの続きを薄く出す。Tab で採る |
| 候補の注釈 | | SKK 辞書の注釈（`/描く;絵を/`）を候補の横に出す |

`z` の記号（`z.` … `z/` ・ `z-` 〜 `zh` ← `zj` ↓ `zk` ↑ `zl` → `z[` 『 `z]` 』）と、送り仮名のある読みを SKK 辞書の送りありの見出し（`かk /書/`）で引くのは、切り替えなしでいつも使える。
