# つまづきの記録

設定の「一般 → つまづきの記録」か入力メニューの「つまづきを記録する」でオンにすると、打っていてつまづいたところを
`~/Library/Logs/sokkou-stumbles.jsonl` に 1 行ずつ残します。既定はオフで、記録は Mac の外には出しません。

| 種類 | いつ残すか |
| --- | --- |
| `deletedAfterCommit` 確定してすぐ消した | 確定から 3 秒以内に、アプリで ⌫ を押した |
| `undidCommit` 確定を取り消した | 確定した直後の ⌃/ |
| `cancelled` 打ちかけを捨てた | Esc・⌃G で未確定の文字列を捨てた |
| `corrected` 自動変換を直した | 文節選択に入って、候補を動かした回数と文節を伸び縮みさせた回数 |
| `retyped` 打ちかけを何度も消した | 打っている途中に ⌫ を 3 回続けた |
| `fixedForm` 字種を手で直した | 打っている途中の ⌃K・⌃Q・⌃L・⌃⇧L（日英の判定や字種が違った） |
| `wrongMode` 違うモードで打って打ち直した | 消してから 5 秒以内にモードを替えた |
| `modeKeyDidNothing` 今のモードへの切り替えキーを押した | モードを取り違えていたか、前の切り替えが効かなかった |
| `slow` 変換が遅かった | キーの処理に 100 ms 以上かかった（10 秒に 1 回まで） |
| `marked` 自分で印をつけた | 入力メニューの「いまつまづいた」 |

どの記録にも、版・アプリのバンドル ID・モードと、直前の 12 キーの並びが付きます。英字と数字は「字」に置き換え、
「読みと候補も残す」をオンにしたときだけ、打った文字と未確定・確定の文字列をそのまま残します。

「つまづきのまとめをコピー」で、種類ごと・アプリごとの数と新しい 40 件を Markdown でクリップボードに入れます。

## GitHub に送る

記録をオンにしたあと、設定の「GitHub に送る」に非公開のリポジトリ（既定は `trkw/sokkou-stumbles`）と token を入れると、
1 時間ごとに、前に送ったあとの記録を `stumbles/<日時>-<Mac ごとの乱数>.jsonl` として送ります。「いま送る」ですぐにも送れます。

- token は fine-grained personal access token で、そのリポジトリだけ・Contents の Read and write だけにする
- token は Keychain（`sokkou.stumbles.github`）に入れ、アプリにもリポジトリにも書かない
- 「読みと候補も残す」がオンなら、打った文字も送る。だから送り先は非公開のリポジトリにする
